2 лаба вариант 6\
Поиск тяжестей:\
Запросить у пользователя ID предмета a. Найти и вывести на экран индексы всех слотов, где лежат предметы его ID строго больше числа a.

3 лаба вариант 6\
Проверка рецептов крафта:\
В input.txt записан список рецептов создания предметов в формате: Название_предмета: ID1 ID2 ID3 (например, Каменный_топор: 1 1 2, где цифры — это ID необходимых ресурсов из инвентаря). Программа должна проверить каждый рецепт, сопоставив требуемые ID с текущим массивом inventory игрока (учитывая количество одинаковых предметов!). В output.txt вывести вердикт по каждому рецепту: [ДОСТУПНО] или [НЕ ХВАТАЕТ РЕСУРСОВ] с указанием названий недостающих компонентов.

4 лаба вариант 6\
Я блинмб Бетмен:\
Ночной лес. Вся карта изначально залита символом ?. При нажатии специальной клавиши (например, R), герой "кричит", и все препятствия в радиусе 5-7 клеток раскрывают себя (отрисовываются нормально) на 2-3 следующих шага, после чего снова скрываются во тьме.

5 лаба вариант 6\
Картография и Биомы (struct MapInfo и enum Biome):\
Добавьте в структуру карты тип биома (enum: Редколесье, Топь, Каменные руины, Кристальная пещера), который случайно выбирается при генерации каждого этажа и меняет процент препятствий и множитель золота (в Топи шаг стоит 2 стамины, в Кристальной пещере — тройное золото). Раз за этаж по кнопке M (за 5 стамины) герой может «зарисовать этаж», чтобы по возвращении домой продать карты в меню за бонусное золото.
